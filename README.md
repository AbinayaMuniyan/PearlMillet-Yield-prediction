# 🌾 AI Technology for Enhancing Pearl Millet Yield
A data-driven machine learning project applying unsupervised learning (SOM, PCA, DBSCAN) to predict and analyze Pearl Millet yield patterns from environmental data.

## 🧾 Abstract
This project uses unsupervised learning algorithms — PCA, DBSCAN, and SOM — to analyze and predict Pearl Millet yield patterns under varying climatic conditions. 
By processing real-world environmental data from Tamil Nadu (2020–2024), the system identifies hidden relationships between rainfall, temperature, soil moisture, and yield, providing insights for sustainable and climate-smart agriculture.

## 📘 Overview
This project explores the application of unsupervised learning algorithms to predict pearl millet yield using environmental factors such as temperature, rainfall, humidity, wind speed, and soil moisture.

## 🧠 Algorithms Used
- Principal Component Analysis (PCA)
- Density-Based Spatial Clustering of Applications with Noise (DBSCAN)
- Self-Organizing Maps (SOM)

## 🧰 Tools & Technologies
- Orange AI Tool
- Python (Pandas, Scikit-learn, MiniSom)
- Data from Tamil Nadu Agriculture Department (2020–2024)

## 📊 Key Results
- SOM produced the most reliable 2025 yield prediction (~2450 kg/ha)
- Identified key climatic influences like rainfall & soil moisture
- Demonstrated data-driven support for climate-resilient farming
